# Renergy Movement

Statische website voor Rens van Zoelen, gebouwd met gewone HTML, CSS en een klein stukje JavaScript.

## Bestanden

- `index.html` bevat de volledige pagina.
- `style.css` bevat alle vormgeving en responsive regels.
- `script.js` sluit het mobiele menu na een keuze.
- `images/` bevat de gebruikte afbeeldingen.

Open `index.html` rechtstreeks in een browser of upload `index.html`, `style.css`, `script.js` en de map `images` naar een webhostingpakket.
